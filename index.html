Código de acesso

Cada ilha tem o seu código, e a DRPM tem outro. A app reconhece o código e mostra só as fichas dessa ilha; o código da DRPM mostra todas as ilhas.

Gerir códigos de acesso (DRPM)

Ao alterar um código, os equipamentos dessa ilha voltam a pedir o código na próxima abertura com rede.

Importar Excel

Use um ficheiro exportado por esta app (folha "Registos") ou uma folha com os mesmos títulos de coluna. Os cagarros são agrupados por ficha (Ilha, Iniciais, Mês, Ano). Se o código do cagarro já existir nessa ficha, o registo é atualizado; caso contrário, é acrescentado.

  1. Uma linha por cagarro, com uma linha de títulos no topo.
  2. Colunas obrigatórias: Ilha, Iniciais, Mês, Ano e Código cagarro.
  3. Datas em formato de data do Excel ou dd/mm/aaaa.

Instalar no iPhone / iPad

  1. Abra esta página no Safari.
  2. Toque no botão Partilhar (quadrado com seta para cima).
  3. Escolha Adicionar ao ecrã principal e toque em Adicionar.

A app fica com ícone próprio, abre em ecrã inteiro e funciona sem rede; os registos são enviados quando a ligação voltar.
