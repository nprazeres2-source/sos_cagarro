Importar Excel

Use um ficheiro exportado por esta app (folha "Registos") ou uma folha com os mesmos títulos de coluna. Os cagarros são agrupados por ficha (Ilha, Iniciais, Mês, Ano). Se o código do cagarro já existir nessa ficha, o registo é atualizado; caso contrário, é acrescentado.

  1. Uma linha por cagarro, com uma linha de títulos no topo.
  2. Colunas obrigatórias: Ilha, Iniciais, Mês, Ano e Código cagarro.
  3. Datas em formato de data do Excel ou dd/mm/aaaa.
